# Contributing

Reno119 is currently a focused Linux desktop project. Bug reports and narrowly scoped fixes are welcome.

When reporting a problem, include:

- Reno119 version
- distribution and desktop/compositor
- relevant game/store source (Steam, Heroic, Lutris, or Custom)
- the exact action that triggered the problem
- relevant diagnostics from Reno119 when available

Please keep changes focused on Reno119's core goal: straightforward, safe RenoDX HDR setup rather than general launcher functionality.
