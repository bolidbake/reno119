# Contributing

Reno119 is primarily a personal-use project that is public in case it is useful to other people. There is no guaranteed support schedule, release cadence, or roadmap.

Bug reports, focused fixes, cleanup, documentation improvements, and practical feature contributions are welcome. Forks are welcome too.

If someone eventually wants to take a more active maintenance role or carry the project forward, that would be welcome rather than discouraged.

When reporting a problem, please include:

- Reno119 version
- distribution and desktop/compositor
- relevant game/store source (Steam, Heroic, Lutris, or Custom)
- the exact action that triggered the problem
- relevant diagnostics from Reno119 when available

Please keep changes reasonably aligned with Reno119's main goal: straightforward, safe RenoDX HDR setup rather than turning it into a general-purpose game launcher.
