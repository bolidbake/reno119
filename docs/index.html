Reno119

No-hassle RenoDX HDR setup for games running through Proton and Wine.

Discover your games, see the recommended setup, and manage RenoDX, ReShade, REFramework, and OptiScaler from one focused Linux-native interface.

Linux library discovery

Steam, Heroic, Lutris, and custom programs can share one library without turning Reno119 into another launcher.

Safer changes

Managed backups, restore points, health checks, and cautious handling of ambiguous RenoDX matches.

Noctalia + Material

Material 3 themes, Noctalia v5 generated palettes, Pure Black surfaces, and live theme reloads.

Build on Arch / CachyOS

sudo pacman -S --needed base-devel cmake ninja qt6-base qt6-declarative

git clone https://github.com/bolidbake/reno119.git
cd reno119
./build.sh

System-wide installation support is being prepared alongside Arch/CachyOS packaging.

The workflow

select game → see recommended setup → install/apply → get HDR working

Advanced controls stay available for troubleshooting, but the main path is intentionally simple.
